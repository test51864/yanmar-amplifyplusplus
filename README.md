## Apple-inspired visual system

The Amplify++ interface has been redesigned around Apple-like product and interface principles while keeping the Yanmar identity:

- system-native typography using the device font stack (no bundled Apple font files)
- generous whitespace and larger content hierarchy
- translucent navigation and floating toolbars
- frosted-glass surfaces with subtle depth
- large rounded cards and restrained shadows
- pill-shaped controls and calmer status treatments
- light and dark modes with Yanmar red used as a deliberate accent
- subtle motion with reduced-motion accessibility support

This is an Apple-inspired look and feel only; the portal does not imply affiliation with Apple.

## Technical setup

This is a static HTML, CSS and JavaScript prototype. It does not require npm or a build step.

Open `index.html` locally or deploy through GitHub Pages.

Data entered into the prototype is stored in the current browser with `localStorage`. It is not shared between devices or users.

## Important prototype limitations

The login is a front-end demonstration and is not secure authentication. The AI functions generate structured demonstration output locally and do not call an external language model. Real user accounts, secure permissions, cloud file storage, analytics integrations, shared reports and generative AI require a backend and approved APIs.

The SEO Readiness Score is an explainable checklist-based assessment. It is not an official Google score and does not guarantee ranking performance.
